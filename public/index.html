Калькулятор налогов по WB API

Подключите ключ WB, выберите период — сервис сам заберёт отчёт и посчитает налог.

Как запустить

  1. Локально: npm install && npm start
  2. В GitHub сам сайт не исполняется как сервер. Для запуска используйте Render/Railway/Fly.io.
  3. На Render: New Web Service → подключить репозиторий → Build: npm install, Start: npm start.
