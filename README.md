# WB Tax App

Приложение берёт данные из WB API и делает предварительный расчёт налога за выбранный период.

## Что реализовано

- Сервер `Express` с endpoint `POST /api/wb-tax/calculate`.
- Запрос отчёта из WB (текущий: `GET /api/v5/supplier/reportDetailByPeriod`).
- Поддержка двух режимов:
  - УСН «Доходы» 6%
  - УСН «Доходы-Расходы» 15% + минимальный налог 1%
- UI для ввода токена, периода и параметров.

## Важно по WB API

По релиз-нотам WB от **15 апреля 2026** старый метод
`GET /api/v5/supplier/reportDetailByPeriod` помечен как deprecated и должен быть отключён **15 июля 2026**.
В следующей итерации стоит перевести интеграцию на:
- `POST /api/finance/v1/sales-reports/list`
- `POST /api/finance/v1/sales-reports/detailed`

## Запуск

```bash
npm install
npm start
```

Откройте: <http://localhost:3000>

## Деплой (чтобы можно было пользоваться «сразу»)

GitHub сам по себе backend не запускает. Нужен хостинг (например Render):

1. Залейте репозиторий на GitHub.
2. Render → New Web Service → выберите репозиторий.
3. Build command: `npm install`
4. Start command: `npm start`
5. После деплоя получите URL, откройте сайт и используйте.
